# Letzter Außenposten

Idle-Aufbauspiel für Handy und PC: Waren herstellen, das Verkaufslager füllen, Arbeiter einstellen und nachts Zombies abwehren. Fünf Maps vom Bauernhof bis zum Robotik-Labor.

## ▶ Spielen

**https://reflex32-stack.github.io/Letzter-aussenposten/**

Als App installieren:
- **Android (Chrome):** Link öffnen → Menü ⋮ → „App installieren“
- **iPhone (Safari):** Link öffnen → Teilen → „Zum Home-Bildschirm“

Die App läuft danach im Vollbild und auch offline. Neue Versionen melden sich im Spiel mit „Neue Version verfügbar“.

## Steuerung

Am Handy irgendwo aufs Feld tippen und ziehen. Am PC WASD/Pfeiltasten oder Maus ziehen.

## Spielstand übertragen

Menü → Ausrüstung → „Meinen Code kopieren“ und auf dem anderen Gerät bei „Code laden“ einfügen.
